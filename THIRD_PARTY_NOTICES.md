# 使用している外部素材のライセンス

このサイト（`index.html` と `backup/` のデザイン案）のアイコンには、次のオープンソースのアイコンを使っています。
SVGの形を `index.html` などに直接書き込んでおり、一部は形を変えて使っています。

## アイコン

| アイコン | 元の素材 | ライセンス |
|---|---|---|
| 電話、トーク（吹き出し）、メール、左右の矢印（くの字）、メニュー、Instagram | Feather Icons（phone, message-circle, mail, chevron-left, chevron-right, menu, instagram） | MIT |
| ハート（脈のような線を追加）、カレンダー（中に線を追加）、トラック（角を丸く変更）、家（中にハートを追加） | Feather Icons（heart, calendar, truck, home）を改変 | MIT |
| 葉っぱ、にんじん、ナイフとフォーク | Lucide（leaf, carrot, utensils） | ISC |
| 矢印、虫めがね（`backup/` の案A・案Cのみ） | Feather Icons（arrow-left, arrow-right, zoom-in） | MIT |

鍋のアイコン（案A）、波線、丸い飾りなどは、このサイト用に作ったものです。

## フォント

Google Fonts から読み込んでいる Zen Maru Gothic、Shippori Mincho、Zen Kaku Gothic New、Noto Sans JP、Outfit は、いずれも SIL Open Font License 1.1 です。
